CASH COUNT — INSTALLABLE WEB APP

Files:
- index.html: app
- manifest.webmanifest: install metadata
- sw.js: offline cache
- icon.svg: app icon

IMPORTANT:
A Progressive Web App can only be installed reliably when served from HTTPS (or localhost). Opening index.html directly from Downloads lets the calculator run, but browser install/offline service-worker features may not work.

Simple free hosting with GitHub Pages:
1. Create a GitHub repository.
2. Upload all four files at the repository root.
3. In repository Settings > Pages, enable deployment from the main branch and root folder.
4. Open the published HTTPS URL in Chrome on Android.
5. Tap Install in the app if shown, or Chrome menu > Install app / Add to Home screen.

History is stored locally in the browser on that device. Use History > Export backup regularly. This app does not automatically upload to Google Drive.
Do not store customer personal information or confidential company data.
